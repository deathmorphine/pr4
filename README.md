# Практична робота №4 — Повнорозмірна клавіатура

**Завдання:** використовуючи шаблон, розробити вебсторінку у вигляді fullsize-клавіатури.

## Виконані вимоги
1. Розмітка клавіатури виконана за допомогою **CSS Grid** (окремі сітки для основного блоку, F-клавіш, навігаційного блоку і цифрового блоку).
2. Підключені кастомні шрифти **Manrope** і **IBM Plex Mono** з Google Fonts.
3. Для корпусу і клавіш реалізовані об'ємні тіні **box-shadow**.
4. Є різні стани клавіш: звичайний, наведення, натиснення, фокус, увімкнений Caps/Num/Scroll Lock. Додатково додані індикатори цих режимів.

## Як запустити
Відкрийте `index.html` у браузері — встановлювати нічого не потрібно.

Для публікації на GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Клавіатура реагує на кліки мишею і натискання фізичних клавіш, а також показує останню натиснуту клавішу й кількість натискань. На вузьких екранах доступна горизонтальна прокрутка.
